# 🚑 Hospital Emergency Room Dashboard

Recently, I worked on an end-to-end Excel project where I built an interactive dashboard to analyze hospital emergency room data.

# 🎯 Objective

To understand patient flow, improve efficiency, and generate insights for better decision-making in emergency services.

# 📊 Key Insights from Dashboard

- Patient admissions show a balanced pattern between admitted and non-admitted cases.
- A significant portion of patients experience delays, highlighting scope for process improvement.
- Certain age groups contribute more to overall patient visits.
- Patient distribution is fairly balanced across gender.
- Most referrals are directed towards specific departments like General Practice and Orthopedics.

# 🛠️ Tools Used

- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Dashboard Design

# 💡 What I Learned

- Converting raw data into meaningful insights.
- Building interactive dashboards in Excel.
- Understanding real-world healthcare data and operations.

This project helped me understand how data can improve operational efficiency and decision-making in critical environments like hospitals.
